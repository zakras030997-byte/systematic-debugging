# Systematic Debugging — ANODHAS AI adaptation

A Codex-compatible skill for evidence-based debugging: establish the cause before correcting behavior, and verify the affected outcome in the environment that failed.

Локальная адаптация Zak Ras / ANODHAS AI исходного скилла [obra/superpowers](https://github.com/obra/superpowers/tree/main/skills/systematic-debugging). Это производная версия, не официальный релиз upstream.

## Что изменено

- Короткая процедура для изолированной ошибки и полный маршрут для сложных сбоев.
- Факты, гипотезы и непроверенные условия разделены явно.
- Диагностика нужной границы: интерфейс → API → очередь → внешний сервис → сохранение результата.
- Безопасные проверки настроек без вывода секретов и пользовательских данных.
- Локальные тесты, установленная версия и реальный пользовательский результат считаются отдельными уровнями проверки.
- Защита чужих изменений при параллельной разработке.
- При неизвестном результате внешней операции: сверка существующей операции перед повтором, сохранение её идентификатора и условий идемпотентности.
- Неподтверждённые проценты и универсальные обещания в актуальных инструкциях убраны. Исторические материалы исходного проекта сохранены и отмечены как исторические.

## Установка

Нужны Node.js/npm и агент с поддержкой SKILL.md:

```sh
npx skills add zakras030997-byte/systematic-debugging --skill systematic-debugging
```

Для установки на уровне пользователя добавьте `--global`. Выберите Codex в установщике. Если одноимённый скилл уже установлен, сначала сохраните его собственные изменения: новая версия может его заменить. Команда установки в этой публикации не запускалась.

Вручную: скачайте репозиторий и поместите его файлы в каталог `systematic-debugging` вашего агента. SKILL.md и связанные справочники должны оставаться вместе.

## Пример использования

```text
Используй $systematic-debugging. Локальная сборка проходит, но публичная форма не показывает результат. Сначала выясни границу сбоя. Не создавай повторную операцию, пока не установлен исход предыдущей. Сервер доступен только для чтения; локальные исправления разрешены.
```

Скилл не предоставляет доступы и не разрешает деплой, платежи, перезапуски или внешние сообщения. Действующие разрешения владельца определяют допустимые действия.

## Проверено в адаптации 2026-10-07

- Валидация skill-creator quick_validate прошла.
- Ссылки на локальные материалы проверены.
- Безопасный Python-пример проверен на пяти вымышленных входах: корректный URL, отсутствие URL, встроенные учётные данные, недопустимый порт, некорректный URL; значения секретов не выведены.
- Пример проверки пути проверен на разрешённом каталоге, корне временного каталога, соседнем каталоге, символьной ссылке наружу и пустом пути.
- Независимый агент разобрал [три вымышленных сценария](test-scenarios.md): ошибка конфигурации, локальный успех при публичном сбое, неизвестный исход внешнего запроса. Реальных серверных операций в этой оценке не было.

Это ограниченная проверка процедуры и примеров. Она не измеряет скорость, качество всей отладки или готовность конкретного продукта. `find-polluter.sh` сохранён без изменения: он запускает тесты, подавляет их ошибки и требует отдельного безопасного окружения. Отсутствие найденного загрязнения не означает, что тесты прошли.
